# قوافل — موقع حجز رحلات سياحية

موقع كامل بـ HTML/CSS/JS لشركة سياحة، بيسمح للعميل إنه يبني رحلته بنفسه:
يحدد **الوجهة**، **ميعاد الرحلة**، **عدد الأيام**، **عدد الأشخاص**، و**الأنشطة** اللي عاوز يعملها، وبيوصلك الطلب في لوحة إدارة بسيطة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع الرئيسي (الهيدر، الوجهات، خطوات الحجز، الفورم، الفوتر) |
| `styles.css` | كل تنسيقات الموقع الرئيسي |
| `script.js` | تفاعل الموقع: القوائم، الفورم متعدد الخطوات، السلايدر |
| `db.js` | طبقة قاعدة البيانات (شرح تفصيلي تحت) |
| `admin.html` / `admin.css` / `admin.js` | لوحة إدارة لعرض ومتابعة الحجوزات |

## إزاي تجرب الموقع

افتح `index.html` في أي متصفح (كروم أو إيدج أو سفاري). مفيش تثبيت ولا سيرفر مطلوب.
لوحة الإدارة موجودة في `admin.html`، وكلمة السر الافتراضية هي:

```
qawafel2026
```

تقدر تغيّرها من الكونسول بالأمر ده وانت فاتح الموقع:

```js
QawafelDB.setAdminPassword("كلمة_سر_جديدة");
```

## قاعدة البيانات — إزاي شغالة دلوقتي، وإزاي تطورها

الموقع ده **بدون سيرفر خلفي (Backend)**، فقاعدة البيانات اللي فيه دلوقتي عبارة عن طبقة تخزين محلية جوه متصفح العميل نفسه (`localStorage`)، متظبطة في ملف `db.js` بشكل منظم زي جدول حقيقي (id, الاسم, الموبايل, الوجهة, التاريخ, الأيام, الأشخاص, الأنشطة… إلخ).

**ده يعني إيه عمليًا؟**
- كل حجز بيتحفظ في متصفح جهاز العميل اللي حجز منه.
- لو فتحت `admin.html` على **نفس الجهاز والمتصفح**، هتشوف الحجوزات دي.
- لو عميل تاني حجز من جهازه هو، الحجز ده مش هيظهر عندك تلقائيًا على جهازك — لأنه مفيش سيرفر مركزي بيجمع كل الحجوزات في مكان واحد.

**عشان تجمع حجوزات كل عملائك في مكان واحد فعلي (وده اللي هيحتاجه أي شركة شغالة فعلاً)، محتاج:**
1. سيرفر خلفي (Backend) بلغة زي Node.js أو PHP أو Python.
2. قاعدة بيانات حقيقية زي MySQL أو PostgreSQL أو MongoDB أو Firebase.
3. استبدال الدوال اللي جوه `db.js` (زي `addBooking` و`getAllBookings`) بنداءات API بتتكلم مع السيرفر بدل `localStorage`.

الكود اتصمم عمدًا بحيث كل حفظ أو قراءة للبيانات بيعدي من خلال دوال `QawafelDB` بس، فلما تيجي تربطه بسيرفر حقيقي مش هتحتاج تغيّر حاجة في الموقع نفسه أو الفورم — بس تستبدل جوه الملف ده.

لو حابب، أقدر أساعدك في الخطوة الجاية دي وأبنيلك سيرفر بسيط (Node.js + قاعدة بيانات) يستقبل الحجوزات ويخزنها بشكل مركزي وآمن.

## تخصيص المحتوى

- أسماء الوجهات، الأنشطة، والصور: في `index.html` تحت `#destinations` و`#activitiesGrid`.
- الألوان والخطوط: في أول `styles.css` تحت `:root`.
- رقم الهاتف والبريد في الفوتر: في `index.html` تحت `.footer-col`.
