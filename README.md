# قوافل — موقع حجز رحلات سياحية

موقع كامل بـ HTML/CSS/JS لشركة سياحة، بيسمح للعميل إنه يبني رحلته بنفسه:
يحدد **الوجهة**، **ميعاد الرحلة**، **عدد الأيام**، **عدد الأشخاص**، و**الأنشطة** اللي عاوز يعملها، وبيوصلك الطلب في لوحة إدارة بسيطة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع الرئيسي (الهيدر، الوجهات، خطوات الحجز، الفورم، الفوتر) |
| `styles.css` | كل تنسيقات الموقع الرئيسي |
| `script.js` | تفاعل الموقع: القوائم، الفورم متعدد الخطوات، السلايدر |
| `db.js` | طبقة قاعدة البيانات (شرح تفصيلي تحت) |
| `admin.html` / `admin.css` / `admin.js` | لوحة إدارة لعرض ومتابعة الحجوزات |

## الإعداد (مرة واحدة بس)

الموقع دلوقتي متوصّل بقاعدة بيانات حقيقية على **Supabase** (Postgres)، فكل حجوزات كل العملاء بتتجمع في مكان واحد فعليًا، بغض النظر عن جهاز أو متصفح مين حجز.

1. **قاعدة البيانات:** روح لمشروعك على Supabase → SQL Editor → افتح ملف `bookings.sql` اللي في المشروع ده وشغّله مرة واحدة. ده بيعمل جدول `bookings` وقواعد الحماية (RLS) اللي بتخلي أي زائر يقدر "يضيف" حجز، وبس المسجّل دخوله (الأدمن) يقدر "يشوف/يعدّل/يحذف".
2. **مفاتيح الاتصال:** من Project Settings → API، انسخ الـ `Project URL` والـ `anon public key`، وحطهم في ملف `supabase-config.js`.
3. **مستخدم الأدمن:** من Authentication → Users → Add user، اعمل إيميل وباسورد لفريق العمل. بيه هيتم الدخول على `admin.html` (تسجيل دخول حقيقي، مش باسورد ثابت في الكود).

بعد كده، `index.html` هيحفظ كل حجز مباشرة في الجدول، و`admin.html` هيعرضهم لحظة بلحظة لأي حد من فريقك يسجل دخول من أي جهاز.

## إزاي تجرب الموقع محليًا

افتح `index.html` في أي متصفح بعد ما تظبط `supabase-config.js`. مفيش سيرفر محلي مطلوب — الموقع بيتكلم مباشرة مع Supabase من المتصفح.

## قاعدة البيانات — إزاي شغالة دلوقتي

كل الحفظ والقراءة بيعدي من خلال دوال `QawafelDB` في ملف `db.js` بس (زي `addBooking`, `getAllBookings`, `updateBooking`...)، وهي بدورها بتكلم Supabase. ده معناه لو حبيت تغيّر مزوّد قاعدة البيانات في المستقبل، التغيير هيكون في الملف ده بس من غير ما تلمس باقي الموقع.

## تخصيص المحتوى

- أسماء الوجهات، الأنشطة، والصور: في `index.html` تحت `#destinations` و`#activitiesGrid`.
- الألوان والخطوط: في أول `styles.css` تحت `:root`.
- رقم الهاتف والبريد في الفوتر: في `index.html` تحت `.footer-col`.
